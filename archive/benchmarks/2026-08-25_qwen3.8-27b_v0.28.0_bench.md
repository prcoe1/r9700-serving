behavioral code line + 3 CI/NVIDIA-only commits). Full stack: vLLM v0.28.0,

## Interpretation

- **Decode (tg32/tg128) is unchanged** within the documented ~±10% swing —
  no regression from the rc2 baseline.
- **pp2048 prefill reads ~3060 t/s, consistently across four runs today** — well
  above both the 08-24 rc2 reading (~1950) and the previously-recorded variance
  band (~1.4-2.6k). Because v0.28.0 is behaviorally identical to rc2 (3 commits:
  DSv4 CI timeout, Gemma-4 FA4 kernel revert, Cython arm64 tilelang pin — none
  touch prefill/attention), this is most likely a session-environment effect
  (fresh rebuild + `just up` prewarm/aiter kernel state) rather than a code
  change. Whatever the cause, it is reproducible on this boot and is not a
  regression.
- TTFT at pp2048 ~660-680ms (vs ~1050ms on the 08-24 rc2 boot), consistent with
  the higher prefill throughput.
