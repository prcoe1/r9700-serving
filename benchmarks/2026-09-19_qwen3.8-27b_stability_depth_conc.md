# 2026-09-19 — Qwen3.8-27B release validation: stability, depth, concurrency

**TL;DR**: full validation of the release stack (v0.29.0 + `#40709`
multi-image patch, live since the 2026-09-19 rebuild). Stability **400/400 +
10/10 + 10/10, 0 errors**; depth sweep matches the 08-27 shape (deep prefill
−4–6%, inside the documented cross-session variance band); concurrency ITL
p50 **880 ms** / p99 **1.38 s** during a 134K prefill, as predicted for the
2048 chunk budget; coherence PASSED everywhere. No regressions — the release
stands.

## Setup

- v0.29.0+rocm100.gfx1201 (rebuilt 2026-09-19 with all local patches incl.
  `#40709`), torch 2.13, AITER v0.1.20.post1, MTP3, `--no-async-scheduling`,
  V2 runner, fp8 KV (calibrated), 262144 max-model-len, TP2, gfx1201 × 2.
- Live profile: qwen3.8-27b (`--max-num-seqs 2`, `--max-num-batched-tokens
  2048`). All suites ran against it (STABILITY_TESTS.md scripts use
  qwen3.6 model names; runs below substitute qwen3.8-27b, thinking off
  unless noted).
- Method: `llama-benchy 0.4.0` for depth/bench (`--pp 2048 --tg 32 --depth
  D --runs 2 --no-cache`, thinking off, single request);
  `benchmarks/conc_itl_probe.py` for concurrency; host-side `requests`
  scripts for stability. Suites ran sequentially (max-num-seqs 2 —
  parallel suites would distort each other).

  by the documented bar (no 500/timeout/garbage).
- Thinking vocab (36.4%) reads lower than the 0.27.0 baseline (52.1%) because
  outputs ran ~2x longer (10k vs 5.6k tokens); all runs EOS-terminated with
  varied conclusions, no loops.
- Long-context model even flagged the synthetic repetitive prompt as
  substance-free in its summaries — a good coherence signal.
