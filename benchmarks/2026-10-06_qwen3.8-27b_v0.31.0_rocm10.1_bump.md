## What's new in the final for this stack

rc3→final is 6 commits, all out-of-path: 3 HiSparse bugfixes (#59494,
#59450, #59309), 1 CI test drop, minimax-m3 transformers-5.18 compat
(#59613), transformers upper bound (#59614). The `#59614` cap means the
rebuilt image runs **transformers 5.17.0** where rc3 ran 5.18.0 (accepted:

## Build (two Dockerfile fixes for 10.1)

1. **amd_smi packaging**: 10.1 ships `/opt/rocm/share/amd_smi` as bare
   sources (no `pyproject.toml` — 10.0 had one), so `pip install --no-deps`
   fails. Runtime stage now copies the version-matched wrapper (27.1.0 ==
   image's `libamd_smi.so`) into the venv site-packages + `import amdsmi`
   smoke check (`Dockerfile.fullbuild`, commented). `LD_PRELOAD` path
   verified still present in 10.1.
2. `site.getsitepath()` does not exist — use
   `sysconfig.get_path('purelib')`.

Image: `vllm-0.31.0+rocm101.gfx1201`. `/version` confirms.
